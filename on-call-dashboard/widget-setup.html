Install the rota widget

The Scriptable widget reads the same live rota feed as this page, so sheet changes flow through from one place. Choose a site on each widget: HGS, QE or both.

SmallCurrent on-call cover for today’s rota day.
MediumToday and tomorrow.
LargeToday plus the following six days.

Set it up once

  1. Install Scriptable from the App Store.
  2. Tap Copy widget script below. Allow clipboard access if iOS asks.
  3. Open Scriptable, tap +, paste the code into a new script, and name it UHB ENT On Call.
  4. On the Home Screen, touch and hold an empty area, tap +, search for Scriptable, then add a Small, Medium or Large widget.
  5. Touch and hold the widget, choose Edit Widget, and select UHB ENT On Call. You can optionally override its default using the Parameter HGS, QE or BOTH.
Prefilled from your saved rota setting. Change it here before copying if you want this widget to use a different default.

Each widget can still have its own site using its Scriptable parameter. With no recognised parameter it uses the default selected above. iOS controls refresh timing, so the update label tells you whether the widget has fresh data or is showing a saved copy.
